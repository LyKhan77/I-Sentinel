Cara hitung durasi & status "belum exit"?

A

Durasi hanya jika ada exit

Belum exit → durasi "berjalan…", tidak dihitung. Rekap akurat, tapi kalau orang lupa lewat gate exit, datanya menggantung.

B

Auto-close di akhir shift

Belum exit sampai akhir shift + toleransi → durasi dihitung sampai akhir shift, ditandai "exit diasumsikan". Tidak ada data menggantung.

C

B + admin bisa koreksi manual

Auto-close seperti B, plus admin bisa edit entry/exit manual dengan catatan (jejak audit sederhana).
