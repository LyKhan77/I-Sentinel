# Audit Log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fitur Audit Log fase 1 — jejak audit auth/konfigurasi/attendance dengan hash chain anti-tamper, retensi 90 hari, API admin, dan halaman sidebar baru `/audit-log`.

**Architecture:** Helper eksplisit `app/services/audit.py` (`audit.record(...)`) dipanggil dari router yang bermutasi, menulis satu baris ke tabel `audit_log` dalam transaksi yang sama dengan aksi. Integritas per baris dijamin rantai SHA-256 (`prev_hash` → `hash`) yang diverifikasi endpoint POST `/api/v1/audit-logs/verify`. Retensi via sweeper thread harian (pola `disk_alert`). UI: halaman Carbon baru dengan filter URL-param, tabel, paginasi prev/next, tombol verifikasi.

**Tech Stack:** FastAPI, SQLAlchemy 2.0 (`Mapped`/`mapped_column`), Alembic, Pydantic v2, pytest + TestClient; React 19 + Carbon (`@carbon/react`), Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-13-audit-log-design.md`

**Penyesuaian katalog hasil eksplorasi (menyimpang dari §3 spec demi mengikuti kode nyata):**
- `nodes.py` tidak punya CRUD → kedua PUT device pin memakai aksi `node.update` dengan `changes={"detector_device"|"face_device": ...}`.
- `credential_profiles.py` tidak punya DELETE → hanya `credential_profile.create` dan `credential_profile.update`.
- Ditambah `storage.sweep` dan `storage.cleanup` (auditing penghapusan data — inti fitur audit).
- Aksi enrollment dirinci: `enrollment.create` (1 foto), `enrollment.batch`, `enrollment.delete` (foto), `enrollment.purge` (biometri penuh).
- **CREATE selalu menyimpan `changes=None`** — nilai lengkap entitas bisa dilihat di entitasnya sendiri; audit hanya membawa metadata perubahan (UPDATE) dan identitas aksi. Ini keputusan eksplisit yang meresolve ambiguitas spec §4.
- `attendance.export` (GET, semua role) juga dicatat sesuai scope "impor/ekspor CSV".

**Branch:** `feat/audit-log` (sudah aktif). Backend commands dijalankan dari `backend/` dengan venv `.venv`; frontend dari `frontend/`.

```python
"""Jejak audit: tulis satu baris audit_log per aksi, dengan rantai hash anti-tamper.

Dipanggil eksplisit dari router/service pada titik mutasi (bukan listener ORM/middleware)
agar presisi, ringan, dan konteks request (actor, ip) selalu tersedia. Semua tulis terjadi
dalam sesi transaksi aksi yang sama — jejak audit komit/rollback atomik bersama aksi.

Rantai hash: setiap baris menyimpan hash dari (prev_hash + field kanonik), sehingga
menghapus/mengubah satu baris memecahkan rantai dan terdeteksi oleh verify().
Penulisan rantai diserialize lewat pg_advisory_xact_lock agar insert konkuren tidak
membuat fork; di SQLite (test) lock dilewati.

Kategori (auth|config|attendance) di-derive dari entitas action lewat _ENTITY_CATEGORY,
bukan prefix mentah — spec §4/§7.
"""
from __future__ import annotations

import hashlib
import json
import logging
import re
from datetime import datetime, timezone

from sqlalchemy import text
from sqlalchemy.orm import Session

from app.models.audit_log import AuditLog
from app.models.user import User

logger = logging.getLogger(__name__)

GENESIS = "0" * 64
_LOCK_KEY = 770013  # kunci pg_advisory_xact_lock khusus rantai audit (konstanta stabil)
_SECRET_KEY_RE = re.compile(r"password|token|secret|credential|api_key", re.IGNORECASE)

# entitas (prefix action) → kategori spec: auth | config | attendance
_ENTITY_CATEGORY = {
    "auth": "auth",
    "attendance": "attendance",
    "employee": "attendance",
    "enrollment": "attendance",
    "shift": "attendance",
    "camera": "config",
    "stream_source": "config",
    "credential_profile": "config",
    "location_group": "config",
    "node": "config",
    "zone": "config",
    "detector_setting": "config",
    "ai_settings": "config",
    "storage_settings": "config",
    "storage": "config",
    "telegram": "config",
}


def _category_for(action: str) -> str:
    entity = action.split(".", 1)[0]
    return _ENTITY_CATEGORY.get(entity, entity)


def _canon_ts(ts: datetime) -> str:
    """Normalisasi timestamp agar deterministik lintas dialect (naive vs aware)."""
    if ts.tzinfo is not None:
        ts = ts.replace(tzinfo=None)
    return ts.strftime("%Y-%m-%dT%H:%M:%S.%f")


def _canon_changes(changes: dict | None) -> str:
    if not changes:
        return ""
    return json.dumps(changes, sort_keys=True, separators=(",", ":"), ensure_ascii=False)


def _chain_hash(prev: str, *, ts: datetime, category: str, action: str,
                actor_label: str | None, target_type: str | None, target_id: str | None,
                changes: dict | None, status: str) -> str:
    payload = "|".join([
        prev, _canon_ts(ts), category, action, actor_label or "",
        target_type or "", target_id or "", _canon_changes(changes), status,
    ])
    return hashlib.sha256(payload.encode("utf-8")).hexdigest()


def _sanitize(changes: dict | None) -> dict | None:
    """Nilai field bernama mirip rahasia diganti '***' (nama field tetap tampil)."""
    if not changes:
        return None
    return {k: ("***" if _SECRET_KEY_RE.search(k) else v) for k, v in changes.items()}


def record(
    db: Session, *, action: str, actor: User | None = None, actor_label: str | None = None,
    target: tuple[str, object, str] | None = None, changes: dict | None = None,
    status: str = "ok", ip: str | None = None, user_agent: str | None = None,
) -> AuditLog:
    """Tambah satu entri audit ke sesi (belum commit — caller yang commit).

    CREATE umumnya dipanggil dengan changes=None (nilai lengkap ada di entitasnya sendiri);
    UPDATE memakai changes={field: nilai_baru}; nilai lama tidak pernah disimpan.
    """
    category = _category_for(action)
    if actor is not None:
        actor_id = actor.id
        actor_label = actor_label or actor.username
    else:
        actor_id = None
    actor_label = actor_label or "system"
    target_type = target_id = target_label = None
    if target is not None:
        target_type, raw_id, target_label = target
        target_id = None if raw_id is None else str(raw_id)
    changes = _sanitize(json.loads(json.dumps(changes, ensure_ascii=False, default=str))
                        if changes else None)
    ts = datetime.now(timezone.utc)
    if db.bind and db.bind.dialect.name == "postgresql":
        db.execute(text("SELECT pg_advisory_xact_lock(:k)"), {"k": _LOCK_KEY})
    last = db.query(AuditLog.hash).order_by(AuditLog.id.desc()).first()
    prev_hash = last[0] if last else GENESIS
    row = AuditLog(
        ts=ts, category=category, action=action, actor_id=actor_id, actor_label=actor_label,
        target_type=target_type, target_id=target_id, target_label=target_label,
        changes=changes, ip=ip, user_agent=user_agent, status=status,
        prev_hash=prev_hash,
    )
    row.hash = _chain_hash(prev_hash, ts=ts, category=category, action=action,
                           actor_label=actor_label, target_type=target_type,
                           target_id=target_id, changes=changes, status=status)
    db.add(row)
    return row


def verify(db: Session) -> dict:
    """Hitung ulang rantai dari baris tertua di window retensi (genesis window)."""
    rows = db.query(AuditLog).order_by(AuditLog.id).all()
    if not rows:
        return {"ok": True, "checked": 0, "first_break_id": None}
    prev = rows[0].prev_hash  # baris tertua di window: prev_hash-nya tidak diverifikasi
    checked = 0
    for r in rows:
        expect = _chain_hash(prev, ts=r.ts, category=r.category, action=r.action,
                             actor_label=r.actor_label, target_type=r.target_type,
                             target_id=r.target_id, changes=r.changes, status=r.status)
        if r.prev_hash != prev or r.hash != expect:
            return {"ok": False, "checked": checked, "first_break_id": r.id}
        prev = r.hash
        checked += 1
    return {"ok": True, "checked": checked, "first_break_id": None}
```

Create `backend/app/services/audit_sweeper.py`:

```python
"""Penyapu retensi audit log: hapus entri lebih tua dari settings.audit_retention_days.

Thread latar pola sama dengan disk_alert/attendance_closer: sesi segar per iterasi,
penghapusan batch agar tidak memblokir lama. Hash chain baris yang tersisa tidak rusak:
setiap baris menyimpan hash-nya sendiri; verifikasi berjalan maju dari baris tertua
di window retensi (genesis window, lihat services/audit.py verify()).
"""
from __future__ import annotations

import logging
import threading
from datetime import datetime, timedelta, timezone

from sqlalchemy.orm import Session

from app.core.config import settings
from app.core.db import SessionLocal
from app.models.audit_log import AuditLog

logger = logging.getLogger(__name__)

BATCH = 5000
INTERVAL_S = 24 * 3600


def sweep_once(db: Session, now: datetime | None = None) -> int:
    """Hapus entri audit lebih tua dari retensi; return jumlah terhapus."""
    now = now or datetime.now(timezone.utc)
    cutoff = now - timedelta(days=settings.audit_retention_days)
    total = 0
    while True:
        ids = [
            r[0]
            for r in db.query(AuditLog.id).filter(AuditLog.ts < cutoff)
            .order_by(AuditLog.id).limit(BATCH).all()
        ]
        if not ids:
            break
        db.query(AuditLog).filter(AuditLog.id.in_(ids)).delete(synchronize_session=False)
        total += len(ids)
    db.commit()
    return total


class AuditSweeper:
    """Thread latar: sweep_once() tiap interval_s; tanpa run_on_start (sweep pertama setelah 1 interval)."""

    def __init__(self, interval_s: float = INTERVAL_S, session_factory=SessionLocal,
                 run_on_start: bool = False):
        self.interval_s = interval_s
        self.run_on_start = run_on_start
        self._session_factory = session_factory
        self._stop = threading.Event()
        self._thread: threading.Thread | None = None

    def start(self) -> None:
        if self._thread is not None and self._thread.is_alive():
            logger.warning("audit sweeper sudah berjalan — start() diabaikan")
            return
        self._stop = threading.Event()
        self._thread = threading.Thread(target=self._loop, daemon=True, name="audit-sweeper")
        self._thread.start()

    def stop(self) -> None:
        self._stop.set()
        if self._thread is not None:
            self._thread.join(timeout=2)

    def _loop(self) -> None:
        if self.run_on_start:
            self._sweep_safe()
        while not self._stop.wait(self.interval_s):
            self._sweep_safe()

    def _sweep_safe(self) -> None:
        db = self._session_factory()
        try:
            removed = sweep_once(db)
            if removed:
                logger.info("audit sweeper removed %s entries", removed)
        except Exception:
            logger.warning("audit sweep failed", exc_info=True)
        finally:
            db.close()


sweeper = AuditSweeper()
```

import logging
from datetime import datetime

from fastapi import APIRouter, Depends, Query
from sqlalchemy import or_
from sqlalchemy.orm import Session

from app.api.deps import require_admin
from app.core.db import get_db

@router.get("", response_model=AuditLogPage)
def list_audit_logs(
    from_: datetime | None = Query(None, alias="from"),
    to: datetime | None = None,
    category: str | None = Query(None, max_length=16),
    action: str | None = Query(None, max_length=48),
    actor: str | None = Query(None, max_length=64),
    target_type: str | None = Query(None, max_length=32),
    target_id: str | None = Query(None, max_length=64),
    status: str | None = Query(None, max_length=16),
    q: str | None = Query(None, max_length=100),
    limit: int = Query(50, ge=1, le=200),
    offset: int = Query(0, ge=0, le=100_000),
    admin: User = Depends(require_admin),
    db: Session = Depends(get_db),
):
    query = db.query(AuditLog)
    if from_ is not None:
        query = query.filter(AuditLog.ts >= from_)
    if to is not None:
        query = query.filter(AuditLog.ts <= to)
    if category:
        query = query.filter(AuditLog.category == category)
    if action:
        query = query.filter(AuditLog.action == action)
    if actor:
        query = query.filter(AuditLog.actor_label == actor)
    if target_type:
        query = query.filter(AuditLog.target_type == target_type)
    if target_id:
        query = query.filter(AuditLog.target_id == target_id)
    if status:
        query = query.filter(AuditLog.status == status)
    if q and q.strip():
        term = q.strip().replace("\\", "\\\\").replace("%", "\\%").replace("_", "\\_")
        pat = f"%{term}%"
        query = query.filter(or_(
            AuditLog.action.ilike(pat, escape="\\"),
            AuditLog.target_label.ilike(pat, escape="\\"),
            AuditLog.actor_label.ilike(pat, escape="\\"),
        ))
    total = query.count()
    items = query.order_by(AuditLog.ts.desc(), AuditLog.id.desc()).offset(offset).limit(limit).all()
    return {"total": total, "items": items}

import { apiFetch } from './client'

export type AuditLogEntry = {
  id: number
  ts: string
  category: string
  action: string
  actor_id: number | null
  actor_label: string
  target_type: string | null
  target_id: string | null
  target_label: string | null

  ip: string | null
  user_agent: string | null
  status: string
}

export type AuditLogPage = { total: number; items: AuditLogEntry[] }
export type AuditVerifyResult = { ok: boolean; checked: number; first_break_id: number | null }

async function call<T>(path: string, init?: RequestInit): Promise<T> {
  const res = await apiFetch(path, init)
  if (!res.ok) {
    const body = await res.json().catch(() => null)
    throw new Error(typeof body?.detail === 'string' ? body.detail : `http ${res.status}`)
  }
  return res.json()
}

export type AuditQuery = {
  from?: string
  to?: string
  category?: string
  action?: string
  actor?: string
  status?: string
  q?: string
  limit?: number
  offset?: number
}

export function listAuditLogs(query: AuditQuery): Promise<AuditLogPage> {
  const params = new URLSearchParams()
  for (const [k, v] of Object.entries(query)) {
    if (v !== undefined && v !== '') params.set(k, String(v))
  }
  const qs = params.toString()
  return call<AuditLogPage>(`/audit-logs${qs ? `?${qs}` : ''}`)
}

export const listAuditActors = () => call<string[]>('/audit-logs/actors')

export const verifyAuditChain = () =>
  call<AuditVerifyResult>('/audit-logs/verify', { method: 'POST' })

function useDebouncedValue<T>(value: T, ms: number): T {
  const [debounced, setDebounced] = useState(value)
  useEffect(() => {
    const timer = setTimeout(() => setDebounced(value), ms)
    return () => clearTimeout(timer)
  }, [value, ms])
  return debounced
}

export default function AuditLogPage() {
  const { t } = useT()
  const [searchParams, setSearchParams] = useSearchParams()
  const filters = useMemo(
    () => ({
      from: searchParams.get('from') ?? '',
      to: searchParams.get('to') ?? '',
      category: searchParams.get('category') ?? '',
      action: searchParams.get('action') ?? '',
      actor: searchParams.get('actor') ?? '',
      status: searchParams.get('status') ?? '',
      q: searchParams.get('q') ?? '',
    }),
    [searchParams],
  )
  const offset = Number(searchParams.get('offset') ?? 0) || 0
  const debouncedQ = useDebouncedValue(filters.q, 300)

  const [page, setPage] = useState<{ total: number; items: AuditLogEntry[] }>({ total: 0, items: [] })
  const [actors, setActors] = useState<string[]>([])
  const [loading, setLoading] = useState(true)
  const [loadFailed, setLoadFailed] = useState(false)
  const [verifyResult, setVerifyResult] = useState<AuditVerifyResult | null>(null)
  const [verifying, setVerifying] = useState(false)
  const reqRef = useRef(0)

  const setParam = (patch: Record<string, string>) =>
    setSearchParams(
      (prev) => {
        const next = new URLSearchParams(prev)
        for (const [k, v] of Object.entries(patch)) {
          if (v) next.set(k, v)
          else next.delete(k)
        }
        return next
      },
      { replace: true },
    )
  // filter berubah → reset ke halaman pertama
  const setFilter = (patch: Record<string, string>) => {
    setVerifyResult(null)
    setParam({ ...patch, offset: '' })
  }

  const refresh = useCallback(async () => {
    const req = ++reqRef.current
    setLoading(true)
    try {
      const data = await listAuditLogs({
        from: filters.from || undefined,
        // date input 'YYYY-MM-DD' → akhir hari agar hari terpilih inklusif
        to: filters.to ? `${filters.to}T23:59:59.999999` : undefined,
        category: filters.category || undefined,
        action: filters.action || undefined,
        actor: filters.actor || undefined,
        status: filters.status || undefined,
        q: debouncedQ || undefined,
        limit: LIMIT,
        offset,
      })
      if (req !== reqRef.current) return
      setPage(data)
      setLoadFailed(false)
    } catch {
      if (req !== reqRef.current) return
      setLoadFailed(true)
    } finally {
      if (req === reqRef.current) setLoading(false)
    }
  }, [filters.from, filters.to, filters.category, filters.action, filters.actor,
      filters.status, debouncedQ, offset])

  useEffect(() => {
    refresh()
  }, [refresh])

  useEffect(() => {
    listAuditActors().then(setActors).catch(() => setActors([]))
  }, [])

  const onVerify = async () => {
    setVerifying(true)
    try {
      setVerifyResult(await verifyAuditChain())
    } catch {
      setVerifyResult(null)
    } finally {
      setVerifying(false)
    }
  }

  const categoryItems: FilterItem[] = [
    { value: '', label: t('audit.filterAll') },
    ...CATEGORIES.map((c) => ({ value: c, label: t(`audit.category.${c}` as TKey) })),

  const actionItems: FilterItem[] = [
    { value: '', label: t('audit.filterAll') },
    ...(ACTIONS[filters.category] ?? []).map((a) => ({ value: a, label: a })),
  ]
  const actorItems: FilterItem[] = [
    { value: '', label: t('audit.filterAll') },
    ...actors.map((a) => ({ value: a, label: a })),
  ]
  const statusItems: FilterItem[] = [
    { value: '', label: t('audit.filterAll') },
    { value: 'ok', label: t('audit.status.ok') },
    { value: 'failed', label: t('audit.status.failed') },
  ]

  const headers = [
    { key: 'ts', header: t('audit.col.time') },
    { key: 'actor', header: t('audit.col.actor') },
    { key: 'action', header: t('audit.col.action') },
    { key: 'target', header: t('audit.col.target') },
    { key: 'status', header: t('audit.col.status') },
    { key: 'ip', header: t('audit.col.ip') },
  ]

  const pageEnd = Math.min(offset + LIMIT, page.total)

  return (
    <div className="app-page">
      <div className="app-page__head">
        <div>
          <h1 className="app-page__title">{t('nav.auditLog')}</h1>
          <p className="app-page__sub">{t('audit.sub')}</p>
        </div>
        <Button size="sm" disabled={verifying} onClick={onVerify} data-testid="audit-verify">
          {t('audit.verify')}
        </Button>
      </div>

      {verifyResult?.ok && (
        <InlineNotification
          kind="success"
          lowContrast
          title={t('audit.verifyOkTitle')}
          subtitle={t('audit.verifyOk', { n: String(verifyResult.checked) })}
          onCloseButtonClick={() => setVerifyResult(null)}
          data-testid="audit-verify-ok"
        />
      )}
      {verifyResult && !verifyResult.ok && (

          kind="error"
          lowContrast
          title={t('audit.verifyBrokenTitle')}
          subtitle={t('audit.verifyBroken', { id: String(verifyResult.first_break_id) })}
          onCloseButtonClick={() => setVerifyResult(null)}
          data-testid="audit-verify-broken"
        />
      )}
      {loadFailed && (

          kind="error"
          lowContrast
          title={t('common.error')}
          subtitle={t('common.loadFailed')}
          onCloseButtonClick={() => setLoadFailed(false)}
        />
      )}

      <div className="audit-toolbar">
        <div className="audit-date">
          <label htmlFor="audit-from">{t('audit.filter.from')}</label>

            data-testid="audit-filter-to"
          />
        </div>
