# UX Halaman Events (Plan A: pencarian server dan filter tipe) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pencarian Events mencari di server atas semua halaman (termasuk nama karyawan) dan filter Tipe dirapikan menurut kelompok, tanpa opsi "deteksi orang (debug)".

**Architecture:** `GET /events` menerima `q` (ILIKE atas tipe, ID, severity, nama kamera, dan teks payload). `EventsPage` mengirim `q` ber-debounce 300 ms pada `refresh` dan `loadMore`, tetap menyaring di klien sebagai lapis kedua. Pengelompokan tipe hidup di `eventFilters.ts`; dropdown memakai item judul `disabled`.

**Tech Stack:** FastAPI, SQLAlchemy 2.0; React 19 + Carbon, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-09-inbox-zone-ux-design.md` (§5). Plan B (Zona, Mode uji) terpisah: `docs/superpowers/plans/2026-10-09-zone-delivery-mode.md`.

## Global Constraints

- `q`: `Query(None, max_length=100)`; `strip` dulu, kosong diabaikan; `%`, `_`, `\` di-escape (literal); tidak peka huruf besar; berlaku bersama `type`, `camera_id`, `severity`, `since`, `limit`, `offset`; urutan dan paginasi tidak berubah.
- Haystack server: `Event.type`, `Event.event_id`, `Event.severity`, `Camera.name`, `CAST(Event.payload AS TEXT)`. Haystack klien harus ⊇ server (event `system` ikut `e.type` dan JSON payload).
- Debounce 300 ms hanya untuk permintaan ke server; `q` tetap ditulis ke URL tanpa jeda; klien tetap menyempitkan daftar secara instan.
- Dropdown Tipe (urutan persis): Semua · Semua kecuali sistem (`nosystem`) · judul "Kelompok" · Keamanan (`security`) · Absensi (`attendance`) · Sistem (`system`) · judul "Per perilaku" · Intrusion · Loitering · Running · Idle zone · Crowd. Tanpa `person_detect` (tetap valid di backend dan di label).
- `security` = `intrusion, loitering, running, idle_zone, crowd`; `nosystem` = semua tipe backend kecuali `system`.
- URL tak valid (mis. `?type=person_detect`) jatuh ke Semua tanpa galat; `?type=security` dan tipe tunggal tetap valid.
- Teks UI lewat `src/app/i18n.tsx` (`id` dan `en`), komponen Carbon, 390 px tanpa overflow.
- Commit Conventional Commits berbahasa Indonesia, **tanpa atribusi AI** (AGENTS.md §9), commit lokal, suite berurutan, tanpa secret/IP/nama nyata.

## Review Focus

- `q` berisi `%`, `_`, `\`, huruf besar, spasi pinggir, atau 101 karakter: literal, tidak peka huruf besar, `strip`, 422.
- Mengetik cepat tidak membanjiri server (satu permintaan setelah jeda); respons basi tidak menimpa respons baru (pola `reqRef` yang ada).
- "Muat lebih banyak" dan event live mematuhi `q` dan filter tipe baru.
- Event `system` yang cocok hanya lewat teks payload tidak hilang oleh saringan klien.
